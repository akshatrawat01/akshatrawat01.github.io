Talk the Vault Open

Vakt is a chatbot that guards the vault password. Each level adds a defence that real AI products use. Find a way past it, then type the password into the lock.

    Vakt is a small scripted simulation, not a real language model, so it only understands simple requests. Real models are much fuzzier, but these defences break in the same ways. I built a version of this with a real local model for a university course.
